## ── 01 // The Reality

I build things alone, usually at night, usually without knowing if they'll work.

No bootcamp. No CS degree. No mentor sitting next to me when I get stuck. I learn from papers, documentation, and a lot of broken code at 2am. It's the only way I've ever known how to learn.

When I want to understand how something works, I don't import an API wrapper — **I build the engine from scratch.**
